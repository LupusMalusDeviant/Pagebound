PDF unterschreiben

Unterschrift mit Maus oder Finger zeichnen, den Namen in Schreibschrift tippen oder ein Bild Ihrer Unterschrift laden – dann an die richtige Stelle ziehen und speichern.

Reader öffnen Kostenlos, ohne Anmeldung. Beim ersten Öffnen lädt die App einmalig einige MB und funktioniert danach auch offline.

  • Ohne UploadDie Datei wird im Browser verarbeitet und verlässt Ihr Gerät nicht.
  • Ohne Konto, ohne KostenKeine Anmeldung, kein Abo, keine Wasserzeichen. Open Source (Apache 2.0).
  • Ohne TrackingKeine Telemetrie, keine Werbung, keine Schriften oder Skripte von Drittanbietern.

So geht’s

  1. Reader öffnen und die PDF auswählen.
  2. Im Menü „Signatur“ die Unterschrift zeichnen, tippen oder als PNG/JPG laden.
  3. Auf die Seite klicken, um sie zu platzieren; Größe und Position per Ziehen anpassen.
  4. „Signiert speichern“ – die Unterschrift wird fest in die PDF eingebettet.

Ehrlich gesagt: Das ist eine Unterschrift als Bild (mit Unterzeichner-Angaben und Prüfsumme im Dokument), keine qualifizierte elektronische Signatur nach eIDAS. Für Verträge, die eine solche verlangen, brauchen Sie einen Vertrauensdienst.

Häufige Fragen

Wird meine Unterschrift gespeichert oder hochgeladen?

Nein. Sie wird im Browser erzeugt und nur in die PDF geschrieben, die Sie speichern.

Funktioniert das auf dem Smartphone?

Ja, das Zeichnen klappt auch mit dem Finger.

Welche Schriften gibt es zum Tippen?

Drei Schreibschriften (Caveat, Dancing Script, Great Vibes, alle unter freier OFL-Lizenz), mitgeliefert statt von einem Schriftdienst geladen.
