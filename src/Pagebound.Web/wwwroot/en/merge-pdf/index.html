Merge PDFs

Combine several PDF files into one or split a large PDF into separate parts – without sending your files anywhere.

Open the tools Free, no sign-up. The first visit downloads a few MB once; after that it also works offline.

  • No uploadYour file is processed in the browser and never leaves your device.
  • No account, no costNo sign-up, no subscription, no watermarks. Open source (Apache 2.0).
  • No trackingNo telemetry, no ads, no third-party fonts or scripts.

How it works

  1. Open “Tools”, choose the “Pages” category and open the first PDF.
  2. Use “Append” to add more PDFs at the end – one after another.
  3. To split instead, set split points between pages.
  4. Save: one merged PDF, or the parts as separate files.

FAQ

How many files can I merge?

There is no fixed limit; only your browser’s memory sets the boundary.

Does the text stay selectable?

Yes. Pages are copied over, not turned into images.
