Pagebound
English · Zur App

PDF-Seiten löschen

Seiten aus einer PDF entfernen, in neue Reihenfolge bringen oder drehen – und das Ergebnis als neue PDF speichern. Alles passiert in Ihrem Browser.

Seiten verwalten öffnen Kostenlos, ohne Anmeldung. Beim ersten Öffnen lädt die App einmalig einige MB und funktioniert danach auch offline.

  • Ohne UploadDie Datei wird im Browser verarbeitet und verlässt Ihr Gerät nicht.
  • Ohne Konto, ohne KostenKeine Anmeldung, kein Abo, keine Wasserzeichen. Open Source (Apache 2.0).
  • Ohne TrackingKeine Telemetrie, keine Werbung, keine Schriften oder Skripte von Drittanbietern.

So geht’s

  1. „Seiten verwalten“ öffnen und die PDF auswählen.
  2. Seiten, die weg sollen, löschen; bei Bedarf per Ziehen umsortieren oder drehen.
  3. „Anwenden & speichern“ – die neue PDF wird heruntergeladen. Das Original bleibt unverändert.

Häufige Fragen

Wird meine PDF hochgeladen?

Nein. Pagebound läuft vollständig im Browser; die Datei wird nicht an einen Server geschickt.

Kann ich gelöschte Seiten zurückholen?

Solange Sie noch nicht gespeichert haben, ja („Wiederherstellen“). Ihr Original wird ohnehin nie überschrieben.

Gibt es eine Größenbegrenzung?

Es gibt kein Kontingent. Sehr große Dateien (mehrere hundert Seiten) brauchen entsprechend Arbeitsspeicher im Browser.
